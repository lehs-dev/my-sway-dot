# my-sway-dot

Personal Sway desktop and shell dotfiles. The repository mirrors the relevant
paths below the home directory, so its contents can be copied directly into
`$HOME` after review.

Included:

- Sway, Waybar, Foot, Fuzzel, Mako, Fish, and OpenRC GUI-session settings
- `Pictures/wall.jpg`, the wallpaper selected by the Sway configuration
- The fonts used by the configuration under `.local/share/fonts/`

No virtual-machine guest-agent startup setting is included.

To install the fonts after copying the files, refresh the font cache:

```sh
fc-cache -f
```
